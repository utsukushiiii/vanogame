# byVanoGame с подробными комментариями

Это отдельная запускаемая учебная копия игры. Во всех файлах `dormgame/*.py`,
в `main.py`, тестах и двух сценариях проверки добавлены русские пояснения.
Оригинальные инструкции Python и строки данных сохранены. Заголовочные файлы
`.h` относятся к C/C++ и зависимостям; для чтения этой игры они не нужны.

## Как читать

1. `main.py` — точка входа; `dormgame/commands.py` — нажатия игрока.
2. `config.py` — числа и единицы; `geometry.py` — координаты и прямоугольники.
3. `model.py` — страницы, бонусы, смерть, контрольные точки и выход.
4. `physics.py` — прыжок, гравитация, пол, стены и грузовые платформы.
5. `pathfinding.py` и `enemies.py` — A* и поведение двух видов врагов.
6. `timing.py` и `app.py` — кадры, шаги, клавиатура и меню.
7. `presentation.py` и `audio.py` — изображение и синтез звука.
8. `tests` и `tools` — как проверены результаты.

Перед каждым методом есть назначение и параметры. Перед каждой значимой
строкой кода есть пояснение. Строки внутри многострочного текста оставлены
нетронутыми, иначе комментарий стал бы частью текста. Закрывающие скобки
тоже отмечены. Исходные комментарии уже являются пояснениями.

`# [исх. 58]` означает строку 58 **обычного** файла, на которую ссылается Word.
Номер в редакторе учебной копии другой. Ctrl+F по `[исх. 58]` находит нужное
место. `SOURCE_LINE_MAP.json` содержит точное соответствие всех строк.

Имена кода сохранены по-английски: переименование мешало бы сравнивать версии.
Пояснения разбирают присваивания, условия, циклы, вычисления и аргументы
рисования. Повторяющиеся операции тоже прокомментированы для чтения с любого места.

## Запуск

Дважды щёлкните `start.bat`. В текущей папке проекта он найдёт уже установленный
Pygame. На другом компьютере распакуйте весь архив в обычную папку, установите
Python 3.12, откройте PowerShell в этой папке и выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Переносить чужую `.venv` не нужно. Единственная игровая зависимость — Pygame.
Документы Word уже готовы; офисные библиотеки для игры не требуются.
На этой машине копия может также использовать `..\..\.venv\Scripts\python.exe`.

## Короткий словарь

- `=` записывает значение, `==` сравнивает; `!=` означает «не равно».
- `self` — текущий объект, `cls` — класс. Поле `self.x` принадлежит этому объекту.
- `if` выбирает ветку, `for` перебирает элементы, `while` повторяет по условию.
- `def` объявляет функцию, `return` завершает вызов и отдаёт результат.
- `True`/`False` — да/нет, `None` — отсутствие значения.
- `list` — список, `tuple` — неизменяемая последовательность, `set` — без повторов,
  `dict` — словарь ключей и значений. Индексы начинаются с 0.
- `and` требует оба условия, `or` хотя бы одно, `not` переворачивает истинность.
- `*items` распаковывает элементы; `**data` передаёт именованные аргументы из словаря.
- `+=` меняет значение на месте присваивания; `%` берёт остаток, `//` округляет деление вниз.
- `dt` измеряется в секундах. Скорость * dt даёт смещение в пикселях.
- `_name` — соглашение о внутреннем имени, а не запрет доступа.
- `-> float` и `x: int` — подсказки типов, не автоматические проверки.
- `Surface` — холст; `blit` копирует картинку; RGB — красный, зелёный, синий 0..255.
- JSON не допускает комментарии. Построчный разбор карт лежит в `data/РАЗБОР_КАРТ.md`.

## Проверка

Из корня этой копии:

```powershell
.\.venv\Scripts\python.exe -S -m unittest discover -v
.\.venv\Scripts\python.exe -m tools.verify_routes
.\.venv\Scripts\python.exe -m tools.verify_pygame
```

Если используется окружение основной папки, замените путь интерпретатора на
`..\..\.venv\Scripts\python.exe`. Параметр `--native` у verify_pygame включает
настоящее окно; без него проверка работает с dummy SDL.

Обычная версия компактнее и удобнее для разработки; эта копия предназначена
для обучения. После изменений комментарии нужно сверять с кодом.
Документы для выступления находятся в `docs`. Полное руководство содержит
все 137 явно объявленных функций и методов игрового пакета.
